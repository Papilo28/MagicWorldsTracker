================================================================
STEP 2: DEPLOY FRONTEND TO HOSTINGER
================================================================

The frontend is the /public folder (static HTML files only).

1. In hPanel → File Manager → navigate to public_html/

2. Upload these files/folders from your /public folder:
     index.html           → public_html/index.html
     reset-password.html  → public_html/reset-password.html
     api.html             → public_html/api.html
     dashboard/           → public_html/dashboard/
     admin/               → public_html/admin/
     merchant/            → public_html/merchant/
     superadmin/          → public_html/superadmin/

   (Do NOT upload src/, node_modules/, .env, package.json)

3. Or via FTP (FileZilla):
   Host:     ftp.magicworldstracker.eu (or your Hostinger FTP host)
   Username: your Hostinger FTP username
   Password: your Hostinger FTP password
   Port:     21
   Upload the above files to /public_html/

STEP 3: SET UP BREVO EMAIL (5 minutes)
================================================================

1. Go to https://app.brevo.com → Sign up free
2. Go to: Account → SMTP & API → API Keys → Generate New Key
3. Copy your API key
4. Add it to Railway environment variables: BREVO_API_KEY=<key>
5. In Brevo: Senders & IPs → Add Sender:
   Email: noreply@magicworldstracker.eu
   Name:  Magic Worlds Tracker
6. Verify domain ownership in Brevo (add DNS TXT record in Hostinger)

STEP 5: IF USING RENDER INSTEAD OF RAILWAY
================================================================

1. Go to https://render.com → New → Web Service
2. Connect your GitHub repo
3. Settings:
   Build Command:  npm install
   Start Command:  node src/server.js
4. Add environment variables (same as Railway above)
5. Free tier spins down after inactivity — Railway is better for production

================================================================
IMPORTANT SECURITY NOTES
================================================================

1. Your .env file is already in .gitignore — NEVER commit it to git
2. All secrets are set as Railway environment variables (safe)
3. Rotate TRACKING_API_SECRET if you think it's been exposed
4. The BREVO_API_KEY in Railway env vars is never visible in code
